# SAMVIDHAN SARTHI - LEARNING ARCHITECTURE RESTRUCTURE DOCUMENT

## PROJECT CONTEXT

Samvidhan Sarthi is NOT a Constitution encyclopedia.

Samvidhan Sarthi is a gamified constitutional literacy platform.

The purpose is not to make users memorize articles.

The purpose is to help citizens understand:

* Rights
* Duties
* Constitutional Values
* Civic Responsibilities
* Real-life Constitutional Application

The target audience includes:

* Students (Class 8+)
* First-time voters
* Youth
* Adult learners
* Citizens with limited constitutional awareness

The platform must feel like:

"Duolingo for Constitutional Literacy"

NOT

"Wikipedia for Constitution"

---

# CORE LEARNING PHILOSOPHY

The platform must move away from information delivery.

The platform must follow experiential learning.

Every learning unit must follow:

Why It Matters
↓
Real-Life Scenario
↓
Constitutional Concept
↓
Case Example
↓
Interactive Assessment
↓
Reinforcement Game

The learner should first experience a problem and then learn the constitutional principle.

Never start with legal definitions.

Always start with relatable situations.

# LESSON TEMPLATE

Each lesson must contain:

## Why It Matters

Explain why an ordinary citizen should care.

Example:

Why should a student know about Fundamental Rights?

How can constitutional knowledge affect daily life?

---

## Real-Life Scenario

Present a relatable situation.

Example:

A school refuses admission because of religion.

Is this fair?

Which constitutional principle applies?

---

## Constitutional Concept

Explain the constitutional provision.

Requirements:

* Simple language
* 8th–10th grade reading level
* No legal jargon
* Maximum clarity

---

## Case Example

Provide a real constitutional case or real civic example.

Examples:

* Kesavananda Bharati
* Maneka Gandhi
* Vishaka
* S.R. Bommai

Case explanations must be simplified.

---

## Interactive Assessment

Assessment should test understanding.

Not memorization.

Avoid:

"Which article number?"

Prefer:

"What constitutional principle is involved?"

---

## Reinforcement Activity

Connect lesson with:

* Matching Game
* Scenario Challenge
* Timeline
* Spin the Article
* Mini Quiz

Learning must end with activity.

# CONTENT WRITING RULES

Every lesson must:

✓ Use plain language

✓ Use real-world examples

✓ Avoid UPSC-style wording

✓ Avoid legal jargon

✓ Explain impact on ordinary citizens

✓ Focus on understanding

✓ Encourage critical thinking

Never write content that feels copied from a civics textbook.

Never generate content that reads like legal commentary.

---

# QUIZ RESTRUCTURE

Current quizzes focus heavily on article numbers.

This must change.

Target ratio:

30% Recall Questions
70% Application Questions

Good Example:

A college denies admission because of caste.

Which constitutional value is being violated?

Bad Example:

Which article abolishes untouchability?
